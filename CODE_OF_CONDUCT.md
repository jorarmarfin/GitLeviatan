# Código de conducta

Este proyecto adopta el espíritu del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Compromiso

Queremos una comunidad abierta y respetuosa, libre de acoso, sin importar experiencia,
identidad, origen o creencias.

## Esperamos

- Trato respetuoso y crítica constructiva.
- Aceptar con gracia la retroalimentación.
- Centrarse en lo que es mejor para la comunidad.

## No toleramos

- Acoso, insultos, ataques personales o discriminación.
- Publicar información privada de otras personas sin permiso.
- Conducta que razonablemente se considere inapropiada en un entorno profesional.

## Aplicación

Los incidentes se reportan en privado a quienes mantienen el proyecto (ver `SECURITY.md`
para el canal de contacto una vez publicado). Quienes mantienen el proyecto pueden
moderar, editar o eliminar contribuciones y vetar a quien infrinja estas normas.
