# ADR 0002 — Licencia GPL-3.0-or-later

**Estado:** Aceptada · **Fecha:** 2026-10-19

## Decisión

El proyecto se licencia bajo GPL-3.0-or-later.

## Motivos

Mantiene libres los derivados, coherente con el lema "El poder de Git, bajo tu control".

## Alternativas descartadas

MIT: permitiría forks cerrados; se prioriza la protección sobre la adopción.

## Pendiente

Verificar la compatibilidad de licencias de las dependencias antes de la primera release pública.
